# 板级、工程层次与 preset 示例

## 示例的用途

下面给出一套示意结构，用于讨论源码归属和参数流向。所有名称与数值均为虚构说明值；不包含具体研究算法、实验工况或用户设备配置，不是可运行的完整 GMP 工程。仓库的 `examples/preset-layout` 提供与本文一致的参数头和编译检查；单独安装 skill 时阅读本文即可理解结构。

```text
example_suite/
├── src/
│   ├── ctl_main.c/h           公共控制对象与既有 GMP 调度
│   ├── user/
│   │   └── ctrl_settings.h   选择参数、统一名称及一致性检查
│   ├── components/           平台无关的功能组件
│   └── preset/
│       ├── board/            板卡时钟、ADC与硬件资源
│       ├── power_device/     功率器件/驱动约束
│       ├── motor/            电机、电角换算和编码器安装参数
│       └── control/          控制执行周期及所选组件参数
└── project/
    ├── target_board/
    │   ├── board/            初始化、寄存器访问、换算与门控
    │   ├── xplt/             当前平台与 GMP 接口的连接
    │   └── ide/              工程定义与链接设置
    └── simulate/
        ├── xplt/             SIL 缓冲区与相同公共逻辑的连接
        └── model/            对象模型与平台仿真依赖
```

不同 GMP suite 的真实目录可能不同，不要求照图重排。图中的关键关系是：两个平台引用同一公共源，board 属于平台，xplt 承担连接，参数按物理归属分配。工程文件通过链接资源或相对路径引用公共源，不在每个配置下复制源码。

## 参数归属

| 类别 | 示例字段 | 原因 |
|---|---|---|
| board | PWM 时钟/频率、ADC 分辨率与参考电压 | 来源于控制板、采样电路和外设配置 |
| power_device | 死区时间、允许母线范围 | 依赖功率级与驱动，不应散落到电机参数中 |
| motor | 极对数、电阻、电感、编码器计数/圈、安装偏置及有效标志 | 电机与反馈安装对象的属性；换电机要重新确认 |
| control | 执行分频、所需算法参数 | 控制实现的需求；本公开示例仅展示执行分频，不提供算法或整定值 |

安装相关参数是否随 motor 或独立 installation preset 管理，由项目的复用对象决定。重点是只有一个权威值，以及换设备时能够明确识别需要重新确认的参数，不能在 board 与 motor 各维护一份独立编码器配置。

## 统一选择，避免参数转发链失控

`ctrl_settings.h` 选取一份 board、power_device、motor 和 control。参数头仅描述自身数值及身份，不相互包含其他类别或控制组。统一映射发生在选择入口，例如：

```c
#define APP_PWM_HZ EXAMPLE_BOARD_PWM_HZ
#define APP_CONTROL_HZ (APP_PWM_HZ / EXAMPLE_CONTROL_DIVIDER)
#define APP_MOTOR_POLE_PAIRS EXAMPLE_MOTOR_POLE_PAIRS
```

这些名称属于示例，不是 GMP 标准宏。实际工程在既有映射层把它们连接到所用版本需要的参数和接口。

示例允许具名构建通过 `APP_CONTROL_PRESET_FILE` 显式选择控制头；没有覆盖时使用手动默认项。每个类别有重复选择检查；频率、分频和 PWM 计数必须能整除，错误在编译时报告。只改变目录名字不会切换控制器，电脑文件修改也不会自动修改已运行的固件。

## 单位及派生值

示例 board 采用 100 MHz PWM 时钟、20 kHz 中心对齐 PWM；`clock/(2×frequency)` 得到 2500 计数。控制分频为 2，因此控制更新为 10 kHz。这里的计算仅示范编译时派生值；不表示任何具体硬件寄存器已经配置或边沿已经验证。

电机参数注明 Ω、H、计数/机械圈和计数偏置；校准有效标志独立于偏置数值。死区以 ns 表示，转换为目标定时器计数时另行检查时钟、取整与边界，不在多个层重复换算。ADC 分辨率和参考电压不能单独决定相电流换算，还需要实际采样链比例、偏置和极性。

模型应读取同一权威参数的受控导出，并检查实际块的有效字段。更改 preset 后，要重新构建受影响的产物；更改模型还需核对保存与重开后的值。参数头编译检查只证明选择和常量一致性，不代表板级驱动或电机运行通过。
