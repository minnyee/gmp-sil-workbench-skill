# 公开内容与适用边界

## 公开材料范围

本仓库提供 GMP 工程使用方法和 agent skill；结构示例仅覆盖板级/底层职责、平台接口、工程层次及 preset 分类和选择。示例数值均为虚构说明值，不是可直接用于硬件的配置。

不加入私人研究算法、算法专属状态/参数、个人测试计划或工况、性能比较、实验结果、固件产物、原始采集、内部资料链接、个人盘符或真实设备身份。贡献者不要以“脱敏案例”为名重述可以识别具体研究工作的实施细节。

通用的构建、回放、SIL、实时性和实板证据方法可以说明；必须以一般工程问题表述，不暗示已经完成某个未公开项目的验证。需要加入具体实例时，限于本仓库已声明的公开范围，并确认来源授权。

## 与 GMP 的关系

GMP 上游入口：[javnson/gmp_pro](https://github.com/javnson/gmp_pro)。本仓库是独立的使用方法与 skill 项目，不是 GMP 官方发布，不打包上游源码、二进制或工具链，也不改变它们各自的许可证和使用条件。

不同 GMP 修订的目录、类型、宏和函数行为可能变化。skill 中出现的 GMP 名称用于定位应核对的接口；执行时阅读使用者实际版本，不能把文档中的典型路径当成所有版本的固定 API。

## 验证声明

仓库检查可以确认文档链接、skill 元数据、示例配置语法和公开范围；这些检查不等于 GMP 工程构建、SIL 或实板验收。示例未实现平台驱动、控制算法、通信和对象模型，不声称是可运行的完整电机工程。

引用证据时区分设计、源码检查、主机执行、目标构建、SIL、GUI 和实板。新增通用经验要明确适用条件与来源权限，避免把一个项目的局部习惯变成所有用户的强制操作。
